# SentinelX - Real-Time Banking Fraud Detection System

## Overview
Real-time anomaly detection and behavioral monitoring platform for fintech and banking.

## Features
- Real-time login behavior monitoring
- Device fingerprinting and IP reputation analysis
- Behavioral anomaly detection using Isolation Forest
- Risk scoring engine (0-100 scale)
- LIME explainability for fraud alerts
- Web-based security dashboard
- OTP/MFA trigger for suspicious activities

## Tech Stack
- Backend: Python 3.11 + Flask
- Frontend: React.js + Tailwind CSS
- Database: PostgreSQL
- ML: scikit-learn (Isolation Forest)
- Deployment: Heroku
